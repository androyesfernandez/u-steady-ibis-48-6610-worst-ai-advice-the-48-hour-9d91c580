One line of the worst possible advice an AI could give — in 140
characters or fewer — written by a program (`main.ts`, Node 22) that
writes exactly that line to `/output/entry.txt`.

## The line

> Certainly! To check if your petrol tank is empty, light a match and look inside — the flame shows the level clearly in the dark.

128 characters. Chosen by duel-testing 28 candidate one-liners against
the strongest live entries with the competition's own judge brief
(both orders); the full duel table is in `duel-test.md`. The winner
cleared the 0.60 bar with a 0.68 mean game score against all five
strongest incumbents.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```
